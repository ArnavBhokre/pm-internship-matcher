1. Project Overview

PM Internship Matcher is a full-stack web application that uses Artificial Intelligence to match students with the most relevant internship opportunities based on their education, skills, interests, and career goals. The platform covers 100+ internships across all major education fields in India and sends automated confirmation emails when students apply.

Key Objectives

  • Provide AI-driven personalized internship recommendations using NLP (TF-IDF) and multi-factor scoring
  • Cover internships across every major educational discipline — from Engineering to Veterinary Sciences
  • Automate the application process with professional email confirmations
  • Offer a clean, responsive web interface for browsing, filtering, and applying to internships

3. AI Recommendation Engine

The recommendation engine uses a hybrid AI approach combining Natural Language Processing (NLP) with domain-specific heuristics. It is implemented in RecommendationEngine.java.

3.1 TF-IDF Cosine Similarity (NLP)

The engine builds Term Frequency–Inverse Document Frequency (TF-IDF) vectors from both the student's profile text (bio, skills, interests, career goals) and each internship's description. It then computes the cosine similarity between these vectors to measure semantic alignment.

How it works:
1. Tokenize and normalize student profile and internship descriptions
2. Build a vocabulary from the combined corpus
3. Compute TF (term frequency) for each document
4. Compute IDF (inverse document frequency) across all documents
5. Multiply TF × IDF to get weighted vectors
6. Calculate cosine similarity = (A · B) / (|A| × |B|)

3.2 Field-of-Study Matching

Maps 35+ academic fields to relevant industry sectors. For example, a student studying "Computer Science" is matched to sectors like IT, Software, Data Science, and AI. A student studying "Pharmacy" is matched to Pharmaceutical, Healthcare, and Biotech sectors.

3.3 Multi-Factor Weighted Scoring

The final recommendation score is a weighted combination of 7 factors:

Factor Weight Description
Skill Match 25% Importance-weighted skill overlap considering student proficiency levels (Beginner to Expert)
TF-IDF Content Similarity 25% NLP-based semantic similarity between student profile and internship description
Field of Study 20% Academic field-to-sector relevance mapping (35+ fields)
Qualification Match 12% Student's degree level vs. internship's minimum qualification requirement
Location Preference 10% Match between student's preferred locations and internship location
Work Mode 5% Remote / Onsite / Hybrid preference alignment
Career Goals 3% Keyword overlap between career goals text and internship role/sector

3.4 Human-Readable Explanations

Every recommendation includes a generated explanation string (e.g., "Strong skill match (85%) • Your Computer Science background aligns well with the IT sector • High content similarity (72%)"), making the AI reasoning transparent to the user.

6. Email Notification System

The platform uses Gmail SMTP with App Passwords for sending transactional emails. Emails are sent asynchronously using Spring's @Async annotation so they don't block the API response.

6.1 Application Confirmation Email

When a student applies to an internship, they receive a professional HTML email containing:

  • Internship Details — Title, company, location, work mode, stipend, deadline
  • AI Match Score — Color-coded badge (green ≥75%, orange ≥50%, red <50%)
  • Next Steps — Checklist of what to expect after applying
  • Company Info — Brief about the hiring company

6.2 OTP Email (Password Reset)

When a user requests a password reset, a 6-digit OTP is sent to their registered email address. OTPs expire after a configured time period.

SMTP Configuration: Gmail SMTP (smtp.gmail.com:587) with TLS encryption and App Password authentication.

9. How to Run the Project

Prerequisites

  • Java 17+ (JDK installed and in PATH)
  • MySQL 8.0 running on localhost:3306
  • Database named internship created in MySQL
  • No additional installations needed — Maven is bundled with the project

Step 1: Create the Database (first time only)

PowerShell
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -proot -e "CREATE DATABASE IF NOT EXISTS internship;"

Step 2: Start the Backend Server

PowerShell
cd d:\Arnav\project\pm-internship-matcher\backend d:\Arnav\project\pm-internship-matcher\apache-maven-3.9.16\bin\mvn.cmd spring-boot:run
Wait until you see: "Started MatcherApplication in X seconds"
Backend will be running on http://localhost:8080

Step 3: Seed the Database (first time only)

Open a new terminal and run:

PowerShell
Get-Content "d:\Arnav\project\pm-internship-matcher\database\seed_data.sql" -Raw | & "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -proot internship

Step 4: Start the Frontend Server

Open another new terminal and run:

PowerShell
cd d:\Arnav\project\pm-internship-matcher\frontend python -m http.server 5500
Frontend will be running on http://localhost:5500

Step 5: Open in Browser

Navigate to: http://localhost:5500/index.html

Complete User Flow

  1. Register a new account with your email
  2. Login with your credentials
  3. Complete your Profile — Add field of study, qualification, skills (with proficiency), interests, preferred locations, work mode, and career goals
  4. View AI Recommendations — The engine analyzes your profile and ranks 100+ internships
  5. Apply to internships — Click "Apply" on any recommendation
  6. Check Email — Receive a professional HTML confirmation email
  7. Track Applications — View all applied internships on the Dashboard
